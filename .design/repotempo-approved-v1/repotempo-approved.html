查看拟定的只读接口
GET /api/v1/repositories
项目列表，支持标签、观察日期与游标分页。
GET /api/v1/repositories/{id}
仓库资料、已保存简介与快照信息。
GET /api/v1/repositories/{id}/observations
指定日期范围内的 Star 观测记录。

这是本次设计提出的接口约定。现有项目的 /repositories 页面返回 HTML，不应当作上述 JSON API 使用。
