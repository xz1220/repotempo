# RepoTempo 已批准的增量调整 · 2026-09-11

本文件记录用户在本次对话中明确批准的要求，不是重新设计或替换 v1 HTML。
仅下述变化优先于 `.design/repotempo-approved-v1/`；其余视觉与技术栈不变。

1. 账户菜单与页面统一叫「Agent 访问」，不再叫「API 访问 / API 接入」。
2. 一个顺序页面，不切换「访问密钥」与「Agent 接入」页签。
3. 用户生成自己的 AK/SK 后，得到可以在本地执行的专属安装指令。
4. 安装结果是 Skill；主路径不依赖 Node 或 `.mjs`。
5. 可复制完整 Agent 指令，其中动态填入刚生成的 AK/SK。
6. 删除全部已读/未读标记功能，保留关注。研究简读与阅读视图不属于已读标记。

## 实施边界

- 沿用浅色界面、Go 模板、原生 JavaScript、真实账户、CSRF 和按账户隔离的只读凭据。
- 初始页面直接显示生成表单；权限/有效期、已有密钥管理可在本页展开。
- 默认 90 天，只读项目与自己的关注；用户可调整范围与期限，并随时撤销。
- 命令和 Agent 指令只在创建密钥的响应中包含 SK；不能从旧密钥恢复 SK。
- 明示指令含凭据及终端/聊天历史风险；关闭、完成、离开页面时清除 DOM 中的 SK 和指令。
- 下载地址不含密钥。先完整下载安装脚本再执行；本地凭据文件权限为 0600。
- 安装支持有 sh、curl、OpenSSL、tar 的 macOS/Linux/WSL，不宣称原生 Windows 零依赖。
- 原有 MCP/Plugin 包保持兼容，但不占用主设置流程。
- 已读状态原在 localStorage，无数据库迁移；不为清理旧标记而删除浏览器其他本地数据。

v1 冻结稿保持原字节不变。本记录未批准其他列表、导航或账户权限变更。
