## 卡片同时展示项目说明和增长数据

卡片包含原始简介、已保存的阅读摘要、来源和解读日期，以及语言、主题、Star、周期增量、增幅、可比样本排行和收录日期。项目名和详情按钮进入详情，另有直接打开 GitHub 的按钮。

摘要只读取数据库已有内容；当前页一次批量查询，不按卡片逐个调用外部服务。AI 阅读与人工说明分别标注，缺失或空白摘要显示“尚未解读”。详情继续展示完整解读和单项目历史图。

这次从实际 README 整理并导入了 10 个项目的中文简读，来源记录为 `codex_readme`，技术备注保留 README 链接和“未运行验证”的边界。其余项目尚未批量解读；本轮没有新增自动模型生成或详情页实时抓取管线。

## 看板删去三个模块

已删除增长平缓榜、项目表现分布和汇总关注度走势。Top 10 按所选周期真实新增 Star 排序，只展示正增长；势头回落比较两个相邻等长周期，不等于 Star 总数下降。

日期、周期、主题筛选，以及当天新入库入口仍保留。数据不足时显示空状态，不用虚构项目补满榜单。
