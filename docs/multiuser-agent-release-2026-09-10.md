## 已开放的接入方式

账户菜单中的 API 访问支持密钥创建、30/90/365 天有效期、读取权限选择、SK 单次展示与立即撤销。
`GET /api/v1/me`、项目列表、项目详情和 `POST /mcp` 均要求签名；浏览器 Cookie 不能代替 API 凭据。

[接入包](../integrations/repotempo-agent/README.md)包含 Node CLI、stdio MCP、Skill 和 Codex Plugin，可从网页下载。
这些工具只读取 RepoTempo 数据，不自行调用语言模型。使用者可将它们连接到自己的 Agent。

密钥每分钟最多接受 120 个请求，每账号最多 10 把有效密钥、每小时 20 次创建、最多保留 100 条记录。
派生签名密钥本身具有签名能力；数据库及备份仍按敏感文件保护。

CSV 导出使用真实筛选范围，一次查询完成，最多 10,000 个项目，不包含私人备注。
