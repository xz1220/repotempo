# GitHub 项目已支持真实标签筛选

2026-09-08 已在 Tencent2 部署 `97252e0`。[GitHub 项目页](https://github-radar.43-160-242-46.sslip.io/repositories?lang=zh-CN)已将主题下拉替换为可搜索标签，并移除发现来源下拉。

## 筛选和卡片使用同一套标签

标签包含 GitHub 原始标签、旧日报标签和有效分类。标签在数据库中筛选，发生在排名、排序和分页之前，不局限于当前一页。

卡片标签可点击，默认预览 8 个，其余可以展开；当前选中的标签优先显示。投资、Agent、Skills 和 SaaS 有对应原始标签时提供快捷入口。

排序依据、观测日期继续保留。增长对比显示“与 1／7／30 天前比”，并注明以观测日期为终点。旧来源、分类链接仍可用，但只显示当前生效条件及清除入口，不再提供下拉选择。

## 已补齐的数据

本次为 4,434 个项目取得当前 GitHub 标签，其中 942 个确认为空数组；24 个仍未知。今天新增的 323 个项目全部完成标签观测。

当前 GitHub 数据共有 37,820 条项目与标签关系、10,808 种标签。旧日报的完整标签另外归入研究标签，覆盖 1,202 个项目，保留 10,223 个标签值，没有再截取前 8 个。

无法解析的 15 个 GraphQL 节点又按永久仓库 ID 使用 REST 核验，均返回 404；原有 9 个 REST 失败没有盲目重试。旧标签没有冒充当前 GitHub 成功观测。

最终导入更新了 4,450 条仓库记录。数据库升级至版本 5，仅在仓库表增加两个标签字段，没有新增业务表。

## 采集和安全边界

日常已有 GitHub API 的完整响应会保存标签；304 响应不会清空标签。未知标签会触发一次完整响应。回填原生标签时清除旧 ETag，避免将不属于同一响应的标签与缓存标记混用。

研究标签使用合并去重，旧资料重放不会覆盖更完整的集合。标签表示当前保存的属性与旧研究资料，不是按观测日期保存的标签变更快照。

部署前已备份。Star 快照、AI 解读、关注、分类关系及原有项目属性逐行核对无变化；仅标签字段、相应缓存标记与更新时间变化。原有 155 条历史外键检查记录没有新增或清除。
